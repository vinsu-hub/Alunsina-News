# Wave 1d: Ingestion features: related stories, LLM model split, images (Codex)

Read docs/tasks/_common.md, docs/DECISIONS.md, Master spec §11, §12, §14, §15. Existing pipeline: `ingest/*.ts` (read the file headers).

**Owns:** `ingest/**`, `config/feeds.ts`, `scripts/check-feeds.ts`, `app/api/ingest/**`, `lib/thresholds.ts` (you may edit the values/text of `RELATED_STORIES`, don't rename exports).

**Change:**
1. **Related Stories linking** (`ingest/related.ts`), run each cycle after clustering: link Stories that are part of the same ongoing situation over time (NOT the same event; that's clustering). Signals: shared named entities/places in titles, same topic, TF-IDF similarity between story centroids in a band below the clustering threshold, time ordering (up to 14 days). Write `story_links` rows (both directions, relation 'earlier'/'later'/'developing', confidence 0–1). Confidence gate per `RELATED_STORIES` in lib/thresholds.ts: only ≥ 0.6 is ever shown. Keep the `text` there accurate to what you implement (Methodology renders it).
2. **LLM model split** (Master spec §15) in `ingest/llm.ts`: Claude Haiku (`claude-haiku-4-5`) for cheap classification: topic label from the fixed TOPICS list plus a yes/no "same event?" check for borderline cluster merges (cosine within 0.05 of the threshold). Claude Sonnet (`claude-sonnet-5`) for synthesis: the neutral 2-sentence summary + emphasis bullets. Use the official `@anthropic-ai/sdk`. Keep the shared instructions/taxonomy in a stable system prompt with prompt caching. Enabled only when an Anthropic credential is configured and `ALUNSINA_LLM !== "off"`; every failure falls back to heuristics. Bound cost per run (e.g. ≤ 40 Haiku calls, ≤ 15 Sonnet calls) and log counts.
3. **Images:** verify image extraction coverage per feed (report share of articles with images per source in `npm run check-feeds -- --images`). Where a feed has no image fields, leave it null. Do NOT scrape article pages. Only store http(s) URLs, never data URIs.
4. **Feeds:** re-run `npm run check-feeds`; try again the ones that were blocked (some may work with an RSS-reader-style User-Agent like `Mozilla/5.0 (compatible; AlunsinaNewsBot/1.0; +https://alunsina.news/methodology)`; identifying honestly is preferred over impersonating a browser). Add verified regional/community/Filipino-language feeds if you can find live ones (e.g. SunStar city editions, Bombo Radyo, Brigada, GMA Regional TV, Philippine Collegian, Rappler regional sections). Only `verified: true` with actual items. Keep ownership statements factual; use "Ownership not yet verified" when unsure.
5. Performance: one ingest cycle should finish < 2 minutes without LLM.

**Acceptance:** `ALUNSINA_PGLITE_DIR=data/pglite-live npm run ingest -- --no-llm` (or the documented equivalent) completes; report feeds ok/failed, article count, image share, stories, story_links ≥ 0.6 count with 3 example pairs; `--dry-run` writes nothing; with `ALUNSINA_LLM=off` no SDK calls; tsc + eslint clean on owned paths. Do not touch the default dev database (the seeded sample edition other workers are designing against).
